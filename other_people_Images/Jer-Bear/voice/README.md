# Jer-Bear's voice

Jerry's clips — for **speaker recognition** and, later, **voice cloning**.

Record using the protocol in `Nebula_Self_Images/voice/README.md` (16 kHz mono WAV,
30–45 s, same phrase list as everyone else, quiet room).

File as `jerbear_<take>_<n>.wav`.

**Note for the mic array:** the Kinect sits high near the roof line, so it's far-field.
Close-mic recordings are *better* training data, but also record a few takes from across
the room — that's the condition the shack mic will actually see.
