# Papa_Bulldog's voice

Dad's clips — for **speaker recognition** and, later, **voice cloning**.

Record using the protocol in `Nebula_Self_Images/voice/README.md` (16 kHz mono WAV,
30–45 s, same phrase list as everyone else, quiet room).

File as `papabulldog_<take>_<n>.wav`.

He sleeps days and walks nights, so pick a moment when he's awake and the house is quiet —
the shack mic will mostly hear him in the dark, and that's the data worth having.
